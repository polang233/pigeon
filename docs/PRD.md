# Meerkat 需求文档

## 一句话

Meerkat 是一个 Mac 小应用：用像素小场景实时展示 Claude Code 把活派给子代理和 Codex 的过程，谁在干活、谁在挂机、哪件事完成了或出错了，一眼就能看到。

名字来自狐獴：它们会站直身子替同伴放哨，正好是这个应用的角色。

## 要解决的问题

Claude Code 会同时派出好几个子代理，也会通过 MCP 或命令行把活交给 Codex。这些动作散落在终端输出里，很难一眼看出：

- 现在有几件事在并行跑，分别交给了谁
- 哪件做完了，结果是什么；哪件出错了
- Codex、Cursor 这些工具到底开着没有

## 使用场景

1. 开着 Claude Code 干活时，把 Meerkat 放在屏幕一角，看任务在 agent 之间飞来飞去。
2. 子代理并行时，看哪个还在跑、哪个卡住了。
3. 想让 Claude 调用 Codex 之前，先点“检测连接”，看 Codex 和 Cursor 在不在线。

## 角色和画面

画面是一间夜里的像素工作室，没有单独的“网关”节点，任务直接从一个 agent 传给另一个。

| 角色 | 形象 | 位置 |
|---|---|---|
| Claude Code | 橙色像素小生物，坐在左边的桌子后面 | 后排左 |
| Codex | 终端显示器机器人，屏幕上是 `>_` 表情 | 后排右 |
| Cursor | 灰色箭头小家伙 | 前排右 |
| 子代理 | Claude 的迷你版，按类型戴小道具（Explore 拿放大镜、审查戴眼镜、Plan 拿写字板） | 前排左，最多 3 张桌子 |
| 狐獴 | 站在中间木箱上放哨，眼睛跟着飞行中的任务转；检测连接时站高、发出雷达波；出错时头顶冒红色感叹号 | 中间 |

各角色不直接使用官方 logo，靠主色、轮廓和小道具来辨认。

## 动作和动效

| 事件 | 画面 |
|---|---|
| Claude 派活 | Claude 打字，气泡里一个字一个字打出任务标题，然后一串像素方块沿弧线蹦向目标，带着标题小标签 |
| 目标收到 | 目标弹一下，Codex 屏幕显示 `!`，桌上的收件盘多一块 |
| 干活中 | 头顶的小卡片播放当前动作：写代码、读文件、搜索、生图、看图、调用工具、跑命令、思考、等你批准 |
| 完成 | 结果方块蹦回 Claude，头顶出现绿色对勾 |
| 出错 | 红色方块、抖动、冒烟，狐獴头顶冒感叹号 |
| 挂机 | 角色变灰，冒 Zzz |
| 没安装 | 位置上只剩一个虚线框 |
| 检测连接 | 狐獴站高张望，发出雷达波，小点飞向每个 agent，再在头顶标出在线、没打开或没装 |

旁边的任务列表显示每件事的标题、交给谁、用时、状态，以及开头的提示词或结果摘要。

## 数据从哪来

1. **Claude Code hooks**：`PreToolUse`、`PostToolUse`（匹配所有工具）和 `SubagentStop`，由 `hooks/forward.sh` 原样转发给应用。
   - `Agent` / `Task` 工具：子代理任务。
   - `mcp__codex*` 工具，或 Bash 里执行 `codex`：Codex 任务。
   - 其他工具：Claude 自己的动作（读文件、搜索、改代码、跑命令等），只用来播动效。
   - 开始和结束按 `tool_use_id` 配对，不按时间顺序。
2. **本机检测**：应用自己看 Codex、Cursor、Claude 有没有安装、有没有在运行。
3. 应用内置一个只监听本机的小服务（`127.0.0.1:47321`）来接收 hook，它随应用启动、随应用退出，不需要单独起网关。接口见 `CONTRACT.md`。

## 限制

- Codex 内部做了什么看不到，只能按任务内容猜一个主要动作，例如提到“图”就播生图、看图、调用工具。
- 子代理内部的工具调用只有在 hook 里带 `agent_type` 时才能归到子代理头上，否则算在 Claude 身上。
- 只看 Claude Code 作为发起方，Codex 或 Cursor 主动派活暂不支持。

## 范围

**这一版（demo）**
- Mac 应用：窗口、内置接收服务、连接检测、应用图标。
- 像素工作室主题和上面所有动效。
- 模拟演示：不接 hook 也能看到完整效果。
- hook 转发脚本和示例配置，不改动任何全局设置。

**之后**
- 主题切换：蚂蚁工坊（蚂蚁排队搬方块）、叽里咕噜办公室（乱码对话气泡和咕噜音效）。核心逻辑和主题已经分开，加主题只需实现同一组方法。
- 解析 `~/.codex/sessions` 的记录，看到 Codex 内部的真实动作。
- 菜单栏常驻、悬浮小窗、置顶。
- 用小模型生成一句话摘要。
- 历史回放。
